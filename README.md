# کیف لقمه 🍱

کیف لقمه یک MVP برای سفارش غذای مدرسه است که والدین می‌توانند با استفاده از آن، غذای روزهای آینده فرزندشان را سفارش دهند.

این پروژه با تمرکز روی رابط کاربری فارسی، طراحی RTL، تجربه کاربری ساده و ساختار کامپوننتی React پیاده‌سازی شده است.

## امکانات پروژه

- ورود والدین با شماره موبایل و کد OTP آزمایشی
- ثبت‌نام والد و اطلاعات فرزند
- نمایش تقویم شمسی واقعی
- انتخاب روز سفارش
- جلوگیری از انتخاب روزهای گذشته
- مدیریت تعطیلات مدرسه
- نمایش حداکثر دو غذای فعال برای هر روز
- سبد خرید
- افزایش، کاهش و حذف غذا
- محاسبه مبلغ سفارش
- صفحه پرداخت نمایشی
- نمایش فاکتور سفارش
- مشاهده سفارش‌های ثبت‌شده
- پنل مدیریت ادمین
- مدیریت غذاها
- افزودن و ویرایش غذا
- فعال یا غیرفعال کردن غذا
- تعریف منوی اختصاصی برای هر روز
- تعیین قیمت متفاوت غذا در روزهای مختلف
- مدیریت تعطیلات
- جستجو و فیلتر سفارش‌ها
- تغییر وضعیت سفارش‌ها
- ذخیره اطلاعات در LocalStorage
- طراحی کاملاً Responsive برای موبایل، تبلت و دسکتاپ
- رابط کاربری فارسی و راست‌چین

## تکنولوژی‌های استفاده‌شده

- Tailwind CSS

- LocalStorage
- تقویم شمسی اختصاصی
